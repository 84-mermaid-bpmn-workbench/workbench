# Web Editor 1.2.0

## Added

- Pan the live diagram by dragging and zoom with the mouse wheel.
- Compact diagram controls with zoom buttons, a percentage/reset button, and a help popup for pan and fit gestures.
- Escape fits and centers the complete diagram using the pane's current dimensions. Open dialogs, menus, and help close before Escape affects the diagram.
- Source font-size controls: A−, A+, and reset to the default size.
- Saved source text, font size, and source-pane width in browser storage. Reloading restores the previous state; empty saved source opens the default example.
- Clear source button with a trash icon.
- Editor favicon.

## Changed

- Moved the 30% and 50% source-pane width buttons into the source pane's title bar.
- Increased pane-title font size for better visibility.
- The live diagram viewport fills the output pane and clips panned content within it.

## Fixed

- Clearing the source leaves an empty preview instead of showing a Mermaid diagram-type error.
- SVG and PNG downloads and Open SVG use the complete clean diagram, without navigation controls or viewport transforms.
- Replacing a diagram or showing an error releases the previous navigation instance and invalidates stale SVG exports.
